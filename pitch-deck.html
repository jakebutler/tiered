Problem

Most agents search first and evaluate source quality later.

That creates fluent answers with weak evidence. The agent can cite pages, but it often never asked which pages should count.

Failure mode 01

Authority is implicit

Search rankings are treated as a proxy for source authority, even when the claim domain demands primary records.

Failure mode 02

Good sources are missed

SEC filings, FDA labels, regulator pages, and journals often require targeted discovery rather than generic SERP queries.

Failure mode 03

Confidence gets overloaded

Provider confidence, model certainty, answer correctness, and source authority collapse into one vague signal.

Tiered improves source discipline.

Architecture

Tiered turns the research question into source policy before discovery.

The policy is not a better prompt. It is an explicit artifact that shapes search, collection, synthesis, and scoring.

01 Research Question User asks a natural-language question that needs evidence.
02 Claim Domain Classify whether source authority means FDA, SEC, regulator, journal, or market source.
03 Source Authority Policy Define Tier 1, Tier 2, and Tier 3 source classes for the claim.
04 Tiered SERP Queries Generate targeted Bright Data searches for each tier.
05 Evidence Substrate Fetch pages, preserve metadata, synthesize with tier-labeled citations.

Healthcare vertical

Start where the cost of weak sourcing is obvious.

Healthcare drug indication and safety claims give the demo a crisp source hierarchy: labels and regulators first, reputable medical context second, summaries last.

Tier Healthcare source class Role
T1 FDA label, DailyMed, manufacturer prescribing information Primary authority for indication, dosage, warnings, contraindications.
T2 NIH, MedlinePlus, Mayo Clinic, peer-reviewed journals Clinical context, patient-facing confirmation, study-backed explanation.
T3 Generic health blogs, SEO summaries, forums Discovery only. Should not carry substantive claims alone.
Example question

What is Ozempic prescribed for, and what are its major warnings?

Baseline search may land on broad explainers. Tiered search explicitly targets FDA and label sources before allowing contextual medical pages.

Validation

Measure the evidence substrate, not just the prose.

The benchmark runs Baseline and Tiered over automated synthetic questions. The primary metric is Authority Coverage: how much of the answer is supported by acceptable Tier 1 or Tier 2 citations.

Primary metric T1/T2

Authority Coverage across substantive answer claims.

Benchmark plan 100
